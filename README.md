# ☕ Programação Orientada a Objetos com Java

Repositório destinado aos meus estudos e exercícios da disciplina de
**Programação Orientada a Objetos**, utilizando Java.

O objetivo deste repositório é organizar as práticas realizadas ao longo
do semestre e facilitar revisões dos principais conceitos de POO.

## 📚 Conteúdos

- Classes e objetos
- Atributos e métodos
- Encapsulamento
- Herança
- Polimorfismo
- Classes abstratas
- Interfaces

Os tópicos serão adicionados conforme o avanço da disciplina.

## 🗂️ Organização

Cada pasta representa um conteúdo estudado e pode conter:

- exercícios resolvidos;
- código Java;
- pequenas anotações;
- conceitos utilizados;
- observações importantes para revisão.

## 🎯 Objetivo

Além de acompanhar minha evolução em Java, este repositório funciona
como material de consulta e revisão da disciplina.
